# 尾牙報到系統：設定與使用步驟

- 報到台（工作人員用）：https://angustsao.github.io/Github/year-end-party/
- 員工個人 QR Code 頁：`https://angustsao.github.io/Github/year-end-party/ticket.html?t=報到代碼`（信裡會附連結）

## 整體流程

```
Excel 名單 ──A1 產生報到代碼──▶ 複製貼到 Google 試算表「名單」 ──▶ 報到台讀取名單
    │
    └──A2 測試信 → A3 用 Outlook 寄出報到信（內含專屬 QR Code）
```

| 檔案 | 用途 |
|---|---|
| `employee-template.xlsx` | 名單範本（Excel） |
| `send-mail.bas` | Excel 巨集：產生報到代碼、用 Outlook 寄報到信 |
| `apps-script.gs` | 貼到 Google 試算表的 Apps Script（報到台的資料庫） |
| `config.js` | 填 Apps Script 網址與活動名稱 |
| `index.html` / `ticket.html` | 報到台 / 員工個人 QR Code 頁 |

> 員工的 QR Code 裡只有一組隨機的「報到代碼」（例如 `KQ7M2PX9AB`），不是員工編號，所以別人沒辦法自己猜出一張可用的 QR Code。

---

## 1. 準備名單（Excel）

1. 下載 [`employee-template.xlsx`](employee-template.xlsx)，在「名單」工作表填入員工資料，然後刪掉範例的 3 列。
2. 第 1 列標題要有：**員工編號、姓名、部門、桌號、葷素、抽獎編號、Email**。
   - **Email 必填**，寄信會用到。
   - 「報到代碼」「寄送狀態」兩欄不用填，巨集會自動產生。
   - 員工編號不能重複。
   - 「葷素」填 葷／素，也可以寫「蛋奶素」，有「素」字的話報到畫面會用綠色特別標示。
3. 用 **另存新檔** 存成 **Excel 啟用巨集的活頁簿（.xlsm）**。

## 2. 放入寄信巨集（Excel）

1. 在 .xlsm 檔按 **Alt + F11** 開啟 VBA 編輯器 → 上方選單 **插入 → 模組**。
2. 在 GitHub 打開 [`send-mail.bas`](send-mail.bas) → 全選複製 → 貼到剛剛的模組裡。
3. 修改最上面的 **活動資訊**：活動名稱、時間、地點、信件主旨、聯絡窗口。
4. 存檔，然後關閉 VBA 編輯器。
5. 按 **Alt + F8** → 執行 **`A1_GenerateCodes`**，「報到代碼」欄就會填好。

> 如果 Excel 顯示「巨集已被停用」，請點黃色提示列上的「啟用內容」。如果檔案是從網路下載的，請先在檔案上按右鍵 → 內容 → 勾選「解除封鎖」。

## 3. 建立 Google 試算表（報到資料庫）

1. 到 [Google 試算表](https://sheets.new) 建立新的試算表，例如命名為「尾牙報到」。
2. 選 **擴充功能 → Apps Script**，刪掉原本的內容，貼上 [`apps-script.gs`](apps-script.gs) 的全部內容，然後按儲存。
3. 回到試算表重新整理，上方會出現 **「尾牙報到」** 選單（第一次使用要授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」）。
4. 點 **尾牙報到 → 建立分頁**，會建好「名單」和「報到紀錄」兩個分頁。
5. 點 **尾牙報到 → 設定工作人員密碼**，這是報到台登入用的密碼。密碼存在 Google，不會出現在程式碼或 GitHub 上。
6. 把名單貼到試算表：在 Excel「名單」工作表按 Ctrl+A、Ctrl+C，再到 Google 試算表「名單」分頁的 **A1** 按 **Ctrl+Shift+V**（只貼上值）。
7. 點 **尾牙報到 → 檢查名單**，確認人數正確，而且沒有重複的員工編號或缺少報到代碼。

### 部署成網頁應用程式

1. 在 Apps Script 右上角選 **部署 → 新增部署作業** → 齒輪 → **網頁應用程式**。
2. 執行身分選 **我**，誰可以存取選 **所有人**，然後按 **部署**。
3. 複製 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
4. 在 GitHub 打開 [`config.js`](config.js) → 鉛筆圖示 → 把網址貼進 `sheetApi`，把 `eventName` 改成你們的活動名稱 → Commit。

```js
window.YEP_CONFIG = {
  sheetApi: "https://script.google.com/macros/s/AKfy.../exec",
  eventName: "2027 年度尾牙"
};
```

> 以後如果修改了 Apps Script 程式碼，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。只是重貼名單的話，不用重新部署。

## 4. 寄送報到信（Outlook）

需要電腦上有 **傳統版 Outlook**，而且已經登入公司信箱。新版 Outlook（New Outlook）不支援巨集寄信，可以在 Outlook 右上角把「新版 Outlook」開關關掉。

1. **Alt + F8 → `A2_SendTestMail`**：寄一封測試信給自己，檢查：
   - QR Code 圖片有顯示
   - 點信裡的「點這裡開啟您的 QR Code」可以開啟個人頁，而且看得到姓名和桌號（這也代表步驟 3 設定成功）
   - 用報到台掃這封信的 QR Code，可以成功報到（測試完記得清除紀錄，見步驟 6）
2. **Alt + F8 → `A3_SendAllMails`**：正式寄出。
   - 每封信之間會間隔 2.5 秒，避免被公司郵件伺服器擋下。190 人大約要 13 分鐘，寄送期間不要操作 Excel。
   - 寄完後「寄送狀態」欄會寫上「已寄送 時間」。失敗的會寫原因，修正後再執行一次 `A3`，就只會寄還沒成功的人。
   - 寄完記得 **存檔**。

**之後如果新增員工**：在 Excel 加一列 → 執行 `A1`（只會幫新的人產生代碼）→ 重新把整份名單貼到 Google 試算表 → 執行 `A3`（只會寄給新的人）。

**某人要重寄**：把那個人的「寄送狀態」清空，再執行 `A3`。

## 5. 活動當天：報到台

1. 每台手機或電腦打開 https://angustsao.github.io/Github/year-end-party/ ，輸入工作人員密碼和這一台的名稱（例如「報到台 1」）。
2. 按 **開啟相機** → 允許使用相機 → 請員工把 QR Code 對準框框。
   - ✅ **綠色「報到成功」**：顯示姓名、桌號、餐點、抽獎編號，素食會用綠色標示
   - ⚠️ **橘色「已經報到過」**：顯示第一次報到的時間和報到台。如果有人轉傳 QR Code，就會出現這個畫面
   - ❌ **紅色「查無此 QR Code」**：不在名單內，請改用人工查詢
   - 每種結果都有不同的提示音，手機也會震動
3. **QR Code 掃不到**：在「輸入員工編號或姓名」打幾個字 → 點選正確的人 → 核對後按 **確認報到**。同名的人會一起列出，可以用部門和員工編號區分。
4. **按錯了**：查詢那個人 → **取消這筆報到**。
5. 電腦也可以接 **USB 條碼掃描槍**：游標停在輸入框，掃描後會直接報到。
6. 上方會即時顯示 **已報到人數 / 總人數**，各台大約每 20 秒同步一次。

**網路斷線時**：報到台會用暫存的名單繼續報到，上方顯示「離線・N 筆待上傳」，恢復連線後會自動補上傳，並在紀錄裡註明「離線補登」。斷線期間別台的報到看不到，同一人在兩台重複報到的話，以先上傳的那筆為準。**有待上傳的資料時，不要按登出。**

## 6. 正式開始前

- 測試完後點 **尾牙報到 → 清除所有報到紀錄**，人數才會從 0 開始。
- 建議前一天用 3～4 台實際裝置，在會場測試一次網路和相機。
- 活動結束後，「報到紀錄」分頁就是完整的報到清單，包含時間、方式（QR／人工）和報到台，可以直接下載成 Excel 給抽獎或會後統計使用。

## 常見問題

| 狀況 | 處理方式 |
|---|---|
| 執行巨集時跳出「有程式正嘗試代表您傳送電子郵件」 | 這是 Outlook 的安全提示（防毒狀態異常時會出現），可以按「允許」，或請 IT 確認防毒軟體狀態 |
| 寄送狀態顯示「QR Code 圖片下載失敗」 | 公司網路擋住了 `api.qrserver.com`，請 IT 開放這個網址，或改用可以連外的網路寄送 |
| 信件裡看不到 QR Code 圖片 | 員工可以點信裡的連結開啟個人 QR Code 頁，現場也可以人工報到 |
| 報到台登入時顯示「連不上 Apps Script」 | 確認 `config.js` 的網址正確，以及部署時「誰可以存取」選的是「所有人」 |
| 報到台顯示「試算表發生錯誤」 | 確認「名單」分頁第 1 列有「員工編號」「姓名」「報到代碼」 |
| iPhone 開不了相機 | 請用 Safari 開啟，並在「設定 → Safari → 相機」選「允許」 |
| 要換工作人員密碼 | 用選單「設定工作人員密碼」修改，各台會被要求重新登入 |

### 個資提醒

- 報到台只會讀取姓名、部門、桌號、餐點和抽獎編號，**Email 不會傳到網頁上**。
- 員工個人頁必須有報到代碼才查得到資料，而且只能看到本人的資訊。
- QR Code 圖片由 api.qrserver.com 產生，只會送出報到代碼，不會送出姓名等資料。
- 活動結束後，建議每台報到裝置都按「登出」，清除裝置上暫存的名單。
