# 你是哪種街貓？｜貓掌守護聯盟 擺攤心理測驗

貓掌守護聯盟擺攤用的心理測驗小程式。民眾先輸入年齡、綽號與居住地區，回答 9 道題目後，系統會算出最像哪一種街貓，再帶出這類街貓的真實處境，以及正確的照顧方式（不隨意餵食、支持 TNVA/R、不棄養、以領養代替購買）。

## 使用方式

整個程式只有一個檔案 `index.html`，不需要安裝。

- **iPad／手機（推薦）**：iPad 無法直接開啟下載的 HTML 檔，請用網址開啟：
  - 線上版（Claude Artifact）：https://claude.ai/artifact/U3YZUFE7hzqMXSY6FvhLLz （預設僅本人登入可看，要給別人用請從頁面的「分享」開放）
  - 或開啟 GitHub Pages（Settings → Pages → 選這個分支的根目錄），任何人都能用網址開啟。
  - 用 Safari 開啟後，點「分享 → 加入主畫面」，就會像 App 一樣全螢幕開啟。
- **筆電**：直接用瀏覽器開啟 `index.html`，不需要網路。

## 內容

| 結果類型 | 街貓 | 重點觀念 |
| --- | --- | --- |
| 街頭老大貓 | 未絕育的橘虎斑公貓 | 絕育可減少打架、FIV 傳播、噴尿與嚎叫 |
| 暗影忍者貓 | 怕人的黑貓 | 尊重距離，交給專業團體用誘捕籠進行 TNVA/R |
| 撒嬌黏人貓 | 疑似被棄養的三花貓 | 掃描晶片、以領養代替購買、不棄養 |
| 社區巡守貓 | 已剪耳的灰虎斑貓 | 認識剪耳記號，絕育貓是社區的一份子 |
| 堅強貓媽媽 | 帶著小貓的玳瑁母貓 | 從源頭減少繁殖，別隨手撿走小奶貓 |
| 好奇冒險貓 | 四處遊蕩的賓士貓 | 拍拍引擎蓋、避免老鼠藥，絕育可縮小遊蕩範圍 |

每份結果頁都會附上：「別這樣做／這樣做才對」對照、TNVA/R 四步驟說明、剪耳辨識、常見問題，最後是「守護宣言」，民眾全部勾選後就可以到攤位領小禮物。

## 攤位小功能

- **攤位統計**：點頁面最下方的「攤位統計」，可以看到每種結果的人數、各年齡層與居住地區人數，以及最近 30 位參加者的年齡、綽號、地區與結果。預設只存在這台裝置；照下方步驟設定後，所有裝置的資料會集中到 Google 試算表（最多保留最新 1000 筆）。
- **自動回首頁**：結果頁閒置 3 分鐘後會自動回到首頁，方便下一位民眾使用。
- **設定**：修改 `index.html` 裡的 `CONFIG`，可以調整單位名稱、分享網址和閒置秒數。
- 題目與計分在 `QUESTIONS` 裡，每個選項會幫對應類型加分，最高分的類型就是結果，同分時隨機選一個。

## 雲端統計設定（Google 試算表）

設定一次，之後每台 iPad／手機完成的測驗都會寫進同一份 Google 試算表，「攤位統計」頁也會顯示所有裝置的合計。試算表最多保留最新的 1000 筆，超過會自動刪除最舊的。

1. 到 [Google 試算表](https://sheets.new) 建立一份新的試算表，名稱例如「貓掌守護聯盟 測驗紀錄」。
2. 點選單「擴充功能 → Apps Script」，把編輯器裡原本的內容全部刪掉，貼上本專案的 `google-apps-script.gs`，按儲存。
3. 點右上角「部署 → 新增部署作業」，齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，第一次會要求授權，用自己的 Google 帳號同意（若出現「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」，這是你自己寫的程式）。
5. 複製產生的「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`），貼到 `index.html` 裡 `CONFIG.cloudUrl` 的引號中，存檔並推上 GitHub。

注意事項：

- 沒網路時，測驗結果會先存在裝置上，等有網路、下一位做完測驗或重新開啟頁面時自動補傳。
- 雲端資料要刪除或匯出，請直接在 Google 試算表操作（攤位上的「清除統計」按鈕在雲端模式會隱藏，避免誤刪）。
- 知道網址的人都能送資料或讀取統計（只有綽號、年齡層、縣市），請不要另外收集電話、姓名等個資。
- 雲端功能只在 GitHub Pages 或自己開啟的檔案中有效；claude.ai 上的線上預覽版無法連到 Google，會只存在本機。
