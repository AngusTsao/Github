# 你是哪種街貓？｜貓掌守護聯盟 擺攤心理測驗

貓掌守護聯盟擺攤用的心理測驗小程式。民眾回答 9 道題目後，系統會算出最像哪一種街貓，再帶出這類街貓的真實處境，以及正確的照顧方式（不隨意餵食、支持 TNVR、不棄養、以領養代替購買）。

## 使用方式

整個程式只有一個檔案 `index.html`，不需要網路也不需要安裝。

- **擺攤（平板／筆電）**：直接用瀏覽器開啟 `index.html`，建議開全螢幕。
- **讓民眾用手機掃 QR Code**：開啟 GitHub Pages（Settings → Pages → 選這個分支的根目錄），再把網址做成 QR Code。

## 內容

| 結果類型 | 街貓 | 重點觀念 |
| --- | --- | --- |
| 街頭老大貓 | 未絕育的橘虎斑公貓 | 絕育可減少打架、FIV 傳播、噴尿與嚎叫 |
| 暗影忍者貓 | 怕人的黑貓 | 尊重距離，交給專業團體用誘捕籠進行 TNVR |
| 撒嬌黏人貓 | 疑似被棄養的三花貓 | 掃描晶片、以領養代替購買、不棄養 |
| 社區巡守貓 | 已剪耳的灰虎斑貓 | 認識剪耳記號，絕育貓是社區的一份子 |
| 堅強貓媽媽 | 帶著小貓的玳瑁母貓 | 從源頭減少繁殖，別隨手撿走小奶貓 |
| 好奇冒險貓 | 四處遊蕩的賓士貓 | 拍拍引擎蓋、避免老鼠藥，絕育可縮小遊蕩範圍 |

每份結果頁都會附上：「別這樣做／這樣做才對」對照、TNVR 四步驟說明、剪耳辨識、常見問題，最後是「守護宣言」，民眾全部勾選後就可以到攤位領小禮物。

## 攤位小功能

- **攤位統計**：點頁面最下方的「攤位統計」，可以看到今天每種結果出現幾次（資料只存在這台裝置的瀏覽器裡）。
- **自動回首頁**：結果頁閒置 3 分鐘後會自動回到首頁，方便下一位民眾使用。
- **設定**：修改 `index.html` 裡的 `CONFIG`，可以調整單位名稱、分享網址和閒置秒數。
- 題目與計分在 `QUESTIONS` 裡，每個選項會幫對應類型加分，最高分的類型就是結果，同分時隨機選一個。
