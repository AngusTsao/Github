# 開啟留言牆與統計分析（GitHub 版）

GitHub Pages 只能放網頁，不能存資料。這個測驗改用 **你自己的 Google 試算表** 當資料庫：
每位玩家玩完會寫入一列，留言牆和統計頁再從試算表讀出來。完全免費，資料只在你的 Google 帳號裡。

大約 10 分鐘就能設定好。

## 1. 建立試算表與 Apps Script

1. 打開 <https://sheets.new> 建立一個新的 Google 試算表，取個名字，例如「巷口的貓 統計」。
2. 上方選單「**擴充功能**」→「**Apps Script**」。
3. 把編輯器裡原本的內容全部刪掉，貼上本資料夾的 [`apps-script.gs`](apps-script.gs) 全部內容。
4. 找到這一行，把引號裡的字改成你自己的密碼（查看統計、刪除留言時要用）：
   ```js
   const ADMIN_KEY = "請改成你自己的密碼";
   ```
   ⚠️ 只在 Apps Script 裡改，**不要**把真正的密碼放到 GitHub。
5. 按「儲存」（磁碟圖示）。

## 2. 部署成網頁應用程式

1. 右上角「**部署**」→「**新增部署作業**」。
2. 齒輪圖示「選取類型」→ 選「**網頁應用程式**」。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。
   （這是 Google 對所有自製腳本都會顯示的警告，腳本只會讀寫這一份試算表。）
5. 複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/.../exec`）。

## 3. 把網址填進 config.js

在 GitHub 打開 `cat-quiz/config.js` → 按鉛筆圖示編輯 → 把網址貼進引號：

```js
window.CAT_QUIZ_CONFIG = {
  sheetApi: "https://script.google.com/macros/s/你的網址/exec"
};
```

按「Commit changes」。約 1 分鐘後網站自動更新。

## 4. 使用

| 功能 | 網址 |
|---|---|
| 測驗 | `https://angustsao.github.io/Github/cat-quiz/` |
| 留言牆（展場螢幕） | `https://angustsao.github.io/Github/cat-quiz/#wall` |
| 統計分析 | `https://angustsao.github.io/Github/cat-quiz/#stats` |

- **留言牆** 不用密碼，每 8 秒自動更新。
- **統計分析** 第一次開啟要輸入 ADMIN_KEY 密碼，這台裝置會記住。之後在測驗頁上方也會出現留言牆和統計的按鈕。
- 在已輸入密碼的裝置上打開留言牆，每則留言旁會有「移除」按鈕。
- 統計頁可以「下載 CSV」，也可以直接打開試算表看 `players`、`messages` 兩個分頁。

## 常見問題

- **試算表沒有資料**：打開統計頁 `…/cat-quiz/#stats`，最上方會自動做「連線測試」並告訴你哪裡有問題：
  - 「連線正常」：會顯示試算表名稱和「打開試算表」連結，資料就寫在那一份。
  - 「連不到 Google Apps Script」：部署的「誰可以存取」不是「所有人」，或網址不是 `/exec` 結尾那個。
  - 「部署的不是本測驗的程式」：貼錯程式了（例如貼成 `street-cat-quiz` 的那份）。
  - 若 Apps Script 是在 script.google.com 單獨建立的（不是從試算表的「擴充功能」打開），
    程式會自動在你的雲端硬碟建立一份「巷口的貓 統計」試算表，資料會寫在那裡。

- **修改了 apps-script.gs 之後**：要在 Apps Script「部署」→「管理部署作業」→ 編輯 →「版本：新版本」→ 部署，網址不變。
- **想清空測試資料**：直接在試算表刪除 `players`、`messages` 分頁裡的資料列（保留第一列標題）。
- **安全性**：網址是公開的，任何人都能送出資料，但只能寫入資料，不能讀取玩家資料或刪除留言（需要密碼）。留言會過濾長度，也不會被試算表當成公式執行。
