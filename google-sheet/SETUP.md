# 連結 Google 試算表（「假如你是一隻流浪貓」）

GitHub Pages 只能放網頁，不能存資料。這個遊戲用 **你自己的 Google 試算表** 當資料庫：
每位玩家玩完會在試算表新增一列，遊戲裡的「大家的選擇」和 📊 統計頁再從試算表讀出加總後的數字。

試算表已經建立好了：**流浪貓測驗統計**
<https://docs.google.com/spreadsheets/d/1byn5EMkcJB5QomAimibdyhkzcYrgys0t9Npr8Pu9vFc/edit>

## 1. 貼上 Apps Script

1. 打開上面的試算表 → 上方選單「**擴充功能**」→「**Apps Script**」。
2. 把編輯器裡原本的內容全部刪掉，貼上本資料夾 [`apps-script.gs`](apps-script.gs) 的全部內容。
3. 按「儲存」（磁碟圖示）。

## 2. 部署成網頁應用程式

1. 右上角「**部署**」→「**新增部署作業**」。
2. 齒輪圖示「選取類型」→「**網頁應用程式**」。
3. 執行身分：**我**；誰可以存取：**所有人** → 按「部署」。
4. 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。
   這是 Google 對所有自製腳本都會顯示的警告，這份腳本只會讀寫這一份試算表。
5. 複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/.../exec`）。

## 3. 把網址填進 config.js

在 GitHub 打開根目錄的 `config.js` → 鉛筆圖示 → 把網址貼進引號 →「Commit changes」：

```js
window.STRAY_CAT_CONFIG = {
  sheetApi: "https://script.google.com/macros/s/你的網址/exec"
};
```

約 1 分鐘後網站自動更新。之後玩家玩完，試算表就會多一列；首頁和結果頁右上角會出現 📊 統計按鈕。

## 試算表的欄位

| 時間 | 年齡區間 | 地區 | 結果 | 最終體力 | 最終飽足 | 第1關 … 第9關 |
|---|---|---|---|---|---|---|
| 台北時間 | 例如「13～17 歲」 | 縣市 | 四種貓咪性格之一 | 0–100 | 0–100 | 該關選了 A／B／C |

每一關的 A／B／C 對應遊戲裡由上而下的選項。可以直接在試算表做樞紐分析、圖表，或下載成 Excel。

## 常見問題

- **確認有沒有連上**：用瀏覽器打開部署網址，應該看到 `"ok":true,"service":"stray-cat"` 和目前的總數。
- **改了 apps-script.gs 之後**：「部署」→「管理部署作業」→ 編輯 →「版本：新版本」→ 部署，網址不變。
- **清空測試資料**：直接在試算表刪掉資料列，保留第一列標題。統計最多 30 秒後更新。
- **隱私**：不記錄暱稱。網頁只讀得到加總後的數字，讀不到任何單筆資料。
- **安全性**：網址是公開的，任何人都能送出資料，但腳本只接受遊戲裡存在的值
  （年齡區間、縣市、性格、A／B／C），其他內容一律拒絕，不會被試算表當成公式執行。
- **離線時玩完**：結果會先存在裝置上，下次打開遊戲時自動補送。
- **Claude 網址版本**（claude.ai/artifact/…）不會寫入這份試算表，它有自己的統計頁。
